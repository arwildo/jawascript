## Operator

Kalimat operator memakai simbol JS (`==`, `===`, `=`, `!`, `&&`, `||`, `<`, `>`), tapi ada padanannya dalam kata:

| Jawa         | JavaScript |
| ------------ | ---------- |
| `lan`        | `&&`       |
| `utawa`      | `\|\|`     |
| `padhaKaro`  | `===`      |
| `oraPadha`   | `!==`      |
| `gedhePadha` | `>=`       |
| `cilikPadha` | `<=`       |
| `gedhe`      | `>`        |
| `cilik`      | `<`        |
